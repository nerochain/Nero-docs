NERO Chain — Agent View

Product: NERO Chain · Category: Layer-1 blockchain with native account abstraction, paymaster gas sponsorship, and Web2-style authentication.

Homepage: https://docs.nerochain.io · Marketing site: https://nerochain.io

Capabilities

  • Native ERC-4337 account abstraction (no bundler-specific tricks).
  • Paymaster gas sponsorship with three payment types (sponsored / prepay ERC-20 / postpay ERC-20).
  • Web2-style auth: social login, password recovery, MetaMask.
  • Public JSON-RPC API (Paymaster) with OpenAPI 3.1 spec.
  • MCP server for documentation retrieval.

Authentication

Long-lived API key sent as X-API-Key header. Keys are issued via the AA Platform. Read the Agent Auth Guide for the full machine-first flow.

OAuth 2.0 is not currently used. Discovery metadata: /.well-known/oauth-protected-resource.
